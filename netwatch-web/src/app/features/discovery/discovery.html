Faixa: {{ target() || '—' }}

Como funciona

  1. Cada endereço da faixa recebe um ping e tentativas de conexão em portas comuns.
  2. A tabela ARP do sistema revela até os equipamentos que bloqueiam essas verificações.
  3. O fabricante é identificado pelo endereço MAC.
  4. Equipamentos já cadastrados têm a última identificação atualizada; os ausentes passam a inativos.

Somente redes privadas e autorizadas podem ser verificadas. A ausência de resposta não significa necessariamente que o equipamento foi desligado.
